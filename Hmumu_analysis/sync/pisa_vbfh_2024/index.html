    Synchronization with Pisa: VBFH 2024¶

    This page documents the synchronization tool implemented to compare the TAMU analysis with the Pisa analysis maintained by Filippo. The current MC study uses the 2024 VBFH signal sample in the VBF signal region, $115 < m_{\mu\mu} < 135$ GeV.

    Open the unweighted/genWeight comparison Open the comparison with all common weights

    What the tool does¶

    The synchronization is split into small tools that can also be run through ./hmumu sync <tool>:

    1. special_sync_submit.py produces one special synchronization skim per NanoAOD file using the Pisa-compatible selection.
    2. special_sync_merge.py merges the tuples and cutflow tables.
    3. compare_filippo_diagnostic.py matches events by run:luminosityBlock:event. For events selected by only one analysis it reports the first selection step failed on the other side.
    4. sync_mc_weights.py evaluates our generator, pileup, muon ID/isolation and trigger weights for the selected events.
    5. compare_filippo_weights.py compares those factors event by event with the Pisa cumulative weights.
    6. plot_filippo_comparison.py produces 17 kinematic distributions, including the TAMU/Pisa ratio. Its ratio uncertainty counts only non-shared events, so the correlation of the common events is retained.

    The Pisa-compatible definitions are stored in config/Run3_2024/selections_sync_filippo_20260925.yaml. The comparison stops at Pisa's HiggsMass step: their following MC_selection is a random selection of approximately half of the events and has no equivalent in our analysis.

    Current inputs¶

    TAMU Pisa
    NanoAOD files 190 (v2 + ext1) the same 190
    generated events 11,190,000 11,190,000
    selection VBF && Signal_Fit through HiggsMass
    mass window 115--135 GeV 115--135 GeV
    $\sum$ genEventSumw 46,762,888 46,762,888

    The sample is VBFH-Hto2Mu_Par-M-125_TuneCP5_13p6TeV_powheg-pythia8, called VBFHto2Mu_M125_powheg in this analysis. Results below were produced on 7 October 2026.

    Event-by-event result¶

    selection result events
    selected by TAMU 2,294,633
    selected by Pisa 2,284,560
    selected by both 2,257,365
    TAMU only 37,268
    Pisa only 27,195

    The shared sample is 98.4% of the TAMU selection and 98.8% of the Pisa selection. Duplicate run:lumi:event keys from v2 and ext1 are counted only once in these figures.

    The dominant residual difference comes from jets: our selection contains 1.2% more events with at least two jets. Events migrate in both directions close to the 25/35 GeV jet thresholds and $m_{jj}=400$ GeV, consistently with different JER random seeds or jet definitions. Smaller differences come from the electron veto and migrations at the dimuon mass-window boundaries.

    Weight comparison¶

    The common weight is

    genWeight × pileup × muon ID/isolation SFs × trigger SF

    The event-by-event comparison uses 2,257,294 uniquely matched events.

    factor sum TAMU / sum Pisa main result
    generator weight 1.0000 identical event by event
    pileup 1.0000 identical event by event
    muon ID and isolation 0.9899 different scale factors
    trigger 0.9910 different scale factors
    complete event weight 0.9809 residual difference driven by muon SFs

    With the normalizations used by each analysis, the expected VBF signal-region yields are:

    weighting TAMU Pisa
    generator weight only 19.94 19.85
    all common weights 19.23 19.51

    Thus TAMU/Pisa is +0.4% with generator weights only and -1.4% with all common weights. The remaining weighted discrepancy is traced primarily to the muon ID/isolation and trigger scale factors.

    Reproducing the comparison¶

    source env.sh
FIL='/eos/home-f/fcattafe/Hmm_sync_valeria/hmm_2024Summer24_VBF-Hto2Mu_M-125_powheg_*_VBF_SignalRegion_diagnostic_ntuples.root'
OUT=$HMUMU_SYNC/confronto_filippo_mc_vbfh

./hmumu sync special_sync_submit --variant filippo_20260925 \
  --dataset VBFHto2Mu_M125_powheg
./hmumu sync special_sync_merge --tag filippo_20260925 \
  --dataset VBFHto2Mu_M125_powheg
./hmumu sync compare_filippo_diagnostic \
  --dataset VBFHto2Mu_M125_powheg --region Signal_Fit \
  --filippo-step HiggsMass --filippo-input "$FIL" --output-dir "$OUT"
./hmumu sync sync_mc_weights --dataset VBFHto2Mu_M125_powheg \
  --output "$OUT/weights_VBF_Signal_Fit.root"
./hmumu sync compare_filippo_weights \
  --ours-weights "$OUT/weights_VBF_Signal_Fit.root" \
  --filippo-input "$FIL" --output-dir "$OUT"
./hmumu sync plot_filippo_comparison \
  --dataset VBFHto2Mu_M125_powheg --region Signal_Fit \
  --filippo-step HiggsMass --filippo-input "$FIL" --weight analysis \
  --ours-weights "$OUT/weights_VBF_Signal_Fit.root" \
  --filippo-weight HiggsMass_cumulativeWeight \
  --output-dir "$HMUMU_WWW/skim_v4/studies/sync/filippo_mc_vbfh_allweights"
